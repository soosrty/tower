1.0.22（60）

新增
- 支持在导出的完整配置中接入自己的 Tailscale 内网（Surge、Stash、Clash 系、sing-box），Auth Key 只保存在本机钥匙串。
- 新增 SSH、TrustTunnel、MASQUE 节点的导入与导出。
- 手动添加 TLS 节点时可填写证书 SHA-256 指纹。
- 网络设置拆分为「国内 DNS（直连）」和「远程 DNS（经代理）」。
- 支持导入 mihomo 子规则（SUB-RULE / sub-rules）。

改进
- 分流规则按各客户端文档输出。表达不了的规则会跳过并在兼容性提示中说明；拦截规则跳过时会在最前面提醒，不再阻止整份导出。
- sing-box：不在规则列表里的国内网站也能拿到国内地址并直连；改用 1.14 的新写法，不再弹出「配置文件已过时」提示。
- Clash 系：不再同时向境外 DNS 直连查询；不在列表里的国内网站可以直连；严格保护下所有 DNS 都经代理解析。
- 修正多个客户端的协议解析与导出问题，涉及 Shadowsocks 加密方式与 UDP、Hysteria 2 端口、IP 节点的 TLS 域名，以及 Karing、Egern 的导入。
- 没有可用节点的策略组不再把上级组的默认选项变成直连，例如「奈飞视频」默认使用「节点选择」。
- Loon 通配符规则、sing-box 来源地址规则的转换更准确。
- iCloud 同步移到后台并减少不必要的同步，地图拖动、缩放和首页滚动更流畅。
- 内置 ACL4SSR 规则更新到最新版本。

修复
- 拖动策略组排序时，规则匹配顺序会被一起改变，导致「节点选择」覆盖 AI、奈飞等专用分流。现在拖动只影响显示；已受影响的方案会自动恢复原始顺序。
- 首页滑到底部时的异常回弹；节点图标在国旗和协议图标之间来回切换。

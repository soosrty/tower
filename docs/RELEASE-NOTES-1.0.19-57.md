# 塔台 1.0.19（57）

- 新增 Anywhere 客户端支持，可导出和一键导入受支持的节点协议。
- 修复部分旧规则方案预览有节点、导出分组却只剩 DIRECT 的问题，统一预览与导出的来源筛选。
- 修复 Surge 远程规则集包含 extended-matching 时被错误展开的问题。
- 改进 iCloud 多设备同步，避免旧设备或空配置覆盖已有数据，并提供冲突恢复入口。
- 修复多设备同步时，订阅节点改名可能丢失取消勾选状态的问题。
- 合并打开 App 时重复触发的同步检查，保留修改后自动同步和回到前台获取更新。
- 同步备份按内容去重，恢复列表最多显示 10 份配置，并自动清理多余的旧备份。

使用 iCloud 同步时，建议将参与同步的设备都更新到此版本。
